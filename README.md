# Discord 棒読みちゃんBot

本ソフトウェアは、Discordのチャンネルから取得できるテキスト情報をBouyomichanで読み上げる機能を
設定画面付きのWindowsアプリとして使えるようにしたものです。

## 実行ファイル.exe の作り方

### 方法A: 自分のPCでビルド
1. Node.js 20 以上をインストール(https://nodejs.org/)
2. `installer.bat`を実行
　　または`このフォルダでPowerShell`を開き、次を実行してください。
   ```
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   npm install
   npm run dist
   ```
3. `DiscordBouyomiBot.exe` ができます。**このフォルダ直下**にだけ作られます(`dist` や `win-unpacked` フォルダは残りません)。これだけを好きな場所に置いて使えます。

`installer.bat` は、ダブルクリックするだけで上の `npm install` と `npm run dist` を自動で行います(コマンドプロンプトで動くため、PowerShellの実行ポリシーの設定は不要です)。Node.js のインストールだけは先に必要です。完了するとこのフォルダが開き、コマンドプロンプトは自動で閉じます(失敗したときだけ、エラーを確認できるよう開いたままになります)。

動作確認だけしたい場合は `npm start` でビルドせずに起動できます。

### 方法B: GitHub Actions でビルド(Node.js を入れたくない場合)
1. このフォルダ一式を GitHub のリポジトリ(`main` ブランチ)にアップロード
2. 自動でビルドが始まります(Actions タブで進み具合を確認できます)。手動で始めるときは、Actions タブ →「Build and Release」→ Run workflow
3. 完了後、リポジトリの **Releases** から `DiscordBouyomiBot.exe` をダウンロード

## 使い方
1. Developer Portal でBotを作成し、**MESSAGE CONTENT INTENT** をON。
   OAuth2 の URL Generator(`bot` スコープ)で、読み上げたいサーバーにBotを招待
2. 追加したBotから取得したトークンを、「Botトークン」へ入力してください。
3. (任意)右上の歯車 → 設定で、棒読みちゃんの実行ファイル(Bouyomichan.exe)を指定。
   指定しておくと、「開始」を押したときに棒読みちゃんが自動で起動します。
   指定しない場合は、棒読みちゃんを先に起動し、HTTP連携プラグインを有効にしておいてください(既定ポート 50080)
4. アプリを起動し、Botトークンを入力 →「テスト」で棒読みちゃんとの接続を確認 →「開始」
5. ログインすると、Botが参加しているサーバー(アイコン・名前)とチャンネルの一覧が表示されます。**読み上げたいチャンネルにチェックを入れてください**。サーバー行右端の ▽ / ▷ で、チャンネル一覧を折りたたみ / 展開できます
6. チェックを入れたチャンネルで発言すると読み上げられます

**チェックが1つもない場合は何も読み上げません**。ログに「読み上げ対象のチャンネルが見つかりません。チャンネルIDを入力してください」と表示されます(ログイン後に一覧からチェックを入れ、「再起動」を押してください)。

画面上部には、棒読みちゃんとの接続状態(● 接続OK / 未接続)とBotの状態が表示されます。
動作中は「開始」ボタンが緑色の「読み上げ中」(暗い表示)になります。

### 設定を変えたとき(再起動)
ログイン中に読み上げチャンネルなどの設定を変更すると、「開始」ボタンが「再起動」に変わります(案内文「設定が変更されています。/「再起動」を押すと再ログインして反映されます。」は、2行で「停止」ボタンの右隣に表示されます。表示する場所は常に確保されているので、出ても画面はずれません)。
押すとログインし直して新しい設定が反映され、棒読みちゃんが「読み上げを開始しました」と読み上げます。
(この読み上げは、通常の「開始」でログインしたときにも行われます。読み上げ対象のチャンネルがない場合は行いません)

### 画面の大きさを変える
- **各枠の高さ**: 読み上げるサーバー・チャンネル / 対象チャンネル一覧 / ログの下にある線をドラッグすると、高さを変えられます(線にマウスを乗せると上下矢印のカーソルになります)。ダブルクリックで元の高さに戻ります。変更した高さは次回起動時も保たれます
- **ウィンドウ**: サイズ・位置・最大化・フルスクリーンの状態を覚えていて、次回も同じ状態で起動します

### カテゴリーの並べ替え
ホーム画面は次の4つのカテゴリー(枠)に分かれています。各枠の右端中央にある「縦線2本」のつまみをマウスでドラッグすると、自由に並べ替えられます(つまみを選んで上下キーでも移動できます)。ドラッグ中は、枠が(上下方向だけ)マウスに追尾し、少し白く表示されます。離すと、その位置に収まります。並び順は次回起動時も保たれます。

1. 発言者名 / 最大文字数 / 自動開始、開始・停止・設定を保存(初期の並びでは一番上)
2. 読み上げるサーバー・チャンネル
3. 読み上げチャンネルID(+ 対象チャンネル一覧)
4. ログ

(Botトークンと棒読みちゃん HTTP連携URLは、設定画面に移動しました)

### 設定画面(右上の歯車)
| 項目 | 説明 |
|---|---|
| 表示サイズ | 文字サイズを 12〜24px で選択(既定 18px)。サンプル枠は最大(24px)のときの大きさで固定されていて、値を変えても枠や下の項目は動かず、枠の中の文字だけが変わります |
| テーマ | ライト(白ベース)/ ダーク(既定) |
| ログの表示項目 | 日付 / 時間 / サーバー名 / チャンネル名 / ユーザー名(アイコン付き)/ ロールの色を反映。それぞれON/OFFでき、サンプルで確認できます(既定はすべてON) |
| 棒読みちゃん 実行ファイル | Bouyomichan.exe の場所。「参照…」で選択できます。空欄なら自動起動しません |
| 停止時に棒読みちゃんも終了 | ON(既定)のとき、「停止」を押したとき(またはアプリ終了時)に、このソフトが起動した棒読みちゃんも終了します。手動で起動していた棒読みちゃんは終了しません |
| 棒読みちゃん HTTP連携URL | 棒読みちゃんのHTTP連携のURL(既定 `http://localhost:50080`)。右の【テスト】で接続と読み上げを確認できます |
| テストで読み上げる文章 | 【テスト】ボタンで読み上げる文章(既定「テスト読み上げです」) |
| Botトークン | Discord Botのトークン。【表示】/【隠す】で見え方を切り替えられます。Windowsの暗号化機能で保存されます |

設定項目は、上から 表示サイズ → テーマ → ログの表示項目 → 棒読みちゃん 実行ファイル → 棒読みちゃん HTTP連携URL → テストで読み上げる文章 → Botトークン の順に並んでいます。Botトークンと連携URLは、「設定を反映する」を押すと保存されます。

画面の一番下には、常に下部バーが表示されます(左:このソフトウェアについて / 右:すべての設定を初期化、その下に変更の状態と「設定を反映する」)。設定項目が増えても、本文だけがスクロールし、バーと重なりません。

**すべての設定を初期化**(ふだんはグレー、マウスを乗せると赤くなるボタン。「設定を反映する」とは少し間隔を空けています)は、確認のあと、すべてを初期状態に戻します。Botトークンと読み上げ対象のチャンネルも消えます。カテゴリーの並び順、サーバーの並び順、各枠の高さ、ウィンドウの大きさも初期化されます。初期値は次のとおりです。

| 項目 | 初期値 |
|---|---|
| 最大文字数 | 255 |
| 表示サイズ | 18 |
| テーマ | ダーク |
| ログの表示項目 | すべてON |
| 棒読みちゃん 実行ファイル | 空欄 |
| 「停止」を押したとき、このソフトが起動した棒読みちゃんも終了する | ON |
| テストで読み上げる文章 | テスト読み上げです |

右下の緑色の「設定を反映する」を押すと、保存して画面全体に反映し、メイン画面に戻ります。「戻る」を押すと、変更を破棄して戻ります。

ログのユーザー名は `[表示名#ユーザーIDの末尾4桁]` の形式で表示します。ロールの色は、ロールに色が設定されている人だけに反映されます(背景に溶けて読みにくい色は、読める濃さに自動で調整します)。

### メイン画面の設定
| 設定 | 説明 |
|---|---|
| 読み上げるサーバー・チャンネル(一覧のチェック) | チェックしたチャンネルだけを読み上げ。サーバーごとに「すべて選択 / 選択解除」もできます。サーバーの左にある縦線2本のつまみをドラッグすると、サーバーの並び順を自由に変えられます(順番は保存され、対象チャンネル一覧も同じ順になります) |
| 読み上げチャンネルID | 一覧のチェックと連動。直接入力も可能(カンマ区切り)。右の【クリア】でチェックをすべて解除 |
| 対象チャンネル一覧 | IDの下の枠に、チェックしたチャンネルをサーバーごとにまとめて表示します。チェックを入れた順番に関係なく、同じサーバーのチャンネルは同じグループに入ります(一覧にないIDは「サーバー不明」)。枠の中の右上にある ▽ / ▷ で、枠ごと折りたためます(折りたたむと、サーバーアイコンと対象チャンネルの数 `(3)` だけを表示)。サーバーがあるときは、この見出しとサーバー一覧の間に横線が入ります。サーバーごとの ▽ / ▷ で、そのサーバーのチャンネルを折りたたみ / 展開もできます。下の線で高さも変えられます |
| 発言者名を読み上げる | 「名前、本文」の形式で読む |
| 最大文字数 | 超えた分は「以下略」(既定 255) |
| 起動時に自動開始 | 保存済みトークンがあれば、起動と同時に接続 |

チャンネルIDは、一覧のチェックで自動入力されます。手入力する場合は、Discordの設定 → 詳細設定 → 開発者モードをON → チャンネルを右クリック →「チャンネルIDをコピー」。

## アイコン
元のデータは `build/icon.svg`、アプリとexeには `build/icon.png` と `build/icon.ico` が使われます。変更したいときは `icon.svg` を編集し、PNGとICOを作り直してください。

## 注意
- トークンは Windows の暗号化機能で保存されます(設定は `%APPDATA%\discord-bouyomi-bot\settings.json`)。それでも他人にトークンを教えたり、スクリーンショットに写したりしないでください。
- exeは署名されていないため、初回起動時にWindows SmartScreenの警告が出ることがあります(自分でビルドしたものなので「詳細情報」→「実行」で起動できます)。
- 起動直後に切断される場合は、ログに出る切断コードを確認してください(4004: トークン不正 / 4014: MESSAGE CONTENT INTENT 未設定)。
- 棒読みちゃんの実行ファイルが見つからない場合は、ログに「棒読みちゃんを確認できません。設定から参照ファイルを確認してください。」と出ます(Botは開始します)。
- すでに起動中の `DiscordBouyomiBot.exe` がある状態で `npm run dist` を実行すると、exeの配置に失敗します。アプリを終了してから実行してください。

## ファイル構成
- `installer.bat` … ダブルクリックでexeを作る(`npm install` → `npm run dist`)。完成した exe は直下にだけ作られます
- `main.js` … アプリ本体(設定・ウィンドウ状態の保存、Botの開始・停止)
- `bot-core.js` … Discord接続と棒読みちゃんへの送信
- `bouyomi-launcher.js` … 棒読みちゃんの接続確認と自動起動
- `preload.js` / `renderer/` … 画面
- `scripts/copy-exe.js` … ビルドしたexeをこのフォルダ直下に置き、dist を削除
- `build/` … アイコン(`icon.svg` / `icon.png` / `icon.ico`)

## 更新(新しい版のお知らせ・自動更新)
- 起動すると、GitHub の最新リリース(https://github.com/silhou-i/DiscordBouyomiBot/releases)を確認します。新しい版があると、画面上部に【● 更新あり】と表示されます。
- 【● 更新あり】(または「このソフトウェアについて」の【更新する】)を押すと、確認のあと新しい exe をダウンロードし、このソフトを終了して入れ替え、自動で起動し直します。読み上げ中は停止されます。
- 「このソフトウェアについて」の【更新を確認】で、いつでも手動で確認できます。
- 確認とダウンロードは、GitHub の Releases だけが相手です(トークンなどの設定は送信しません)。ダウンロードした exe は、大きさ・exe の形式・チェックサムを確かめてから入れ替えます。通信できないときは、何も表示しません。
- `npm start` で動かしているとき(単体exeではないとき)は、【更新する】でダウンロードページを開きます。
- 新しい版は、`main` ブランチに push すると GitHub Actions が自動でビルドして Releases に公開します。版は `package.json` の `version` と `buildInfo.build`(ビルド番号。新しい版を出すたびに +1)で決まります。

## 表示サイズ・このソフトウェアについて

- 設定の「表示サイズ」スライダーには12〜24pxの目盛りがあります。
- 設定画面の左下「このソフトウェアについて」をクリックすると、別ウィンドウでバージョン、GitHubのURL(https://github.com/silhou-i/DiscordBouyomiBot)、更新の確認、クレジットとライセンス(node.js / electron のリンク)を表示します。【閉じる】で閉じます。
- 読み上げチャンネルIDの右の【クリア】は、読み上げるサーバー・チャンネルのチェックをすべて解除します。
- 設定画面の「変更はまだ反映されていません」は、「設定を反映する」ボタンの左隣に表示されます。
- アイコンは水色(#5CC2D3)の円形です。
